# Banking Data Analytics Project

## Project Overview
This project focuses on analyzing simulated SBI-inspired banking data using MySQL and Microsoft Excel to understand banking operations and generate meaningful business insights.

## Dataset Overview
The project contains 6 relational tables with a total of 16,380 records.

| Table | Records |
|---|---:|
| Customers | 1,000 |
| Branches | 30 |
| Accounts | 1,500 |
| Transactions | 10,000 |
| Loans | 350 |
| Loan Payments | 3,500 |
| **Total** | **16,380** |
